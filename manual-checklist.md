# Yayın öncesi manuel kontrol listesi

- [ ] `.env.local` yalnızca yerelde ve hosting ortamında tanımlı; Git'e eklenmemiş.
- [ ] Supabase SQL migration hatasız çalıştı.
- [ ] E-posta doğrulaması ve yönlendirme URL'leri ayarlı.
- [ ] Yeni kayıt `profiles` kaydı oluşturuyor.
- [ ] Kullanıcı yalnızca kendi profilini ve puan geçmişini görebiliyor.
- [ ] Normal kullanıcı görev ekleyemiyor ve rol/bakiye değiştiremiyor.
- [ ] Admin rolü yalnızca güvenilir yönetim kanalından verildi.
- [ ] Görev tamamlama fonksiyonu oturum doğruluyor.
- [ ] Sahte puan gönderme etkisiz.
- [ ] Aynı görev ikinci kez puan kazandırmıyor.
- [ ] Rate limiting / abuse monitoring yapılandırıldı.
- [ ] Gizlilik ve kullanım metinleri uzman incelemesinden geçti.
- [ ] Yedekleme ve geri yükleme denendi.
- [ ] HTTPS ve production URL ayarlandı.
- [ ] Gerçek ödeme/çekim özellikleri kapalı; ayrıca hukuki ve güvenlik onayı olmadan açılmayacak.
